# 阿修羅（Asyura）

PHP製のサーバー設置型・複数サイト対応アクセス解析ツールです。アクセス解析、逆アクセスランキング、相互リンク、相互RSS、過去記事再配信、お知らせ、相互リンク依頼を1つの管理画面で扱えます。

## 主な機能

- サイト単位の非同期JavaScript計測タグ
- PV、日次UU、内部・外部・表示パーツクリック、流入元、人気ページ、端末・ブラウザ・OS、リアルタイム解析
- http/https、www、末尾スラッシュ、計測パラメーターのURL正規化
- 旧URL、別ドメイン、iframe・外部ツール経由URLの手動統一
- 検索エンジン・不要流入元の除外
- 3日集計を初期値とした逆アクセスランキング
- A〜Eの相互リンク表示場所
- A〜Jの相互RSS表示場所
- HTML/CSSとショートコードによる表示デザイン
- 1サイトへの複数RSS登録
- RSS内の画像だけを利用する画像RSS（OGP補完・No Image補完なし）
- 24時間の受け取りアクセス割合による相互RSS配分
- 優遇、特別、弱小サイト救済、除外の組み合わせ
- 過去記事台帳とランダム再配信RSS
- 相互リンク依頼フォーム、受付番号、申請状況確認、登録・解除通知
- お問い合わせ上部の定型文2種類と自由入力文
- サイト別・全体のお知らせ
- 年次CSV/ZIPエクスポート、アーカイブ閲覧、エクスポート後のDB削除
- WordPress風の管理画面

## 動作環境

- PHP 8.1以上
- MySQL 8.0以上、またはMariaDB 10.5以上
- Apache 2.4以上（Nginxでも利用可能）
- PHP拡張：PDO MySQL、mbstring、cURL、SimpleXML、ZipArchive
- HTTPS推奨

## インストール

1. リポジトリ一式をサーバーへ配置します。
2. ブラウザで `https://設置URL/install.php` を開きます。
3. DB名、DBユーザー、DBパスワードを入力します。
4. インストーラーが設置URLを自動判定し、DB・テーブル・`config/config.php`を自動作成します（DBホストは`127.0.0.1`、ポートは`3306`です）。
5. `login.php`からログインします。

初期ログイン情報：

```text
ユーザー名：admin
パスワード：password
```

強制変更はしません。公開サーバーでは、ログイン後に「設定」から変更することを推奨します。

DBユーザーにデータベース作成権限がない場合は、空のDBを先に作成し、そのDB名をインストーラーへ入力してください。テーブルは自動作成されます。

### XAMPP

`htdocs/Asyura`へ配置した場合：

```text
インストール：http://localhost/Asyura/install.php
ログイン：http://localhost/Asyura/login.php
```

Apacheの`mod_rewrite`と`.htaccess`を有効にしてください。

## cron

30分ごとに実行します。管理画面の「設定」に専用URLが表示されます。

URL方式：

```text
https://設置URL/cron/run.php?key=自動生成キー
```

CLI方式：

```bash
php /サーバー上のパス/Asyura/cron/run.php
```

cronはRSS取得、相互RSS配分計算、保存期限を過ぎたデータの整理を行います。同時実行はDBロックで防止します。

## 計測タグ

「サイト管理」でサイトを登録すると専用タグが発行されます。登録サイトの全ページへ同じタグを設置します。

```html
<script src="https://設置URL/assets/tracker.js"
        data-site-id="サイト専用ID"
        data-site-key="サイト専用キー"
        async></script>
```

タグは非同期で動作します。阿修羅への通信失敗が設置サイトの表示を止めることはありません。

## 保存期間の初期値

| データ | 保存期間 |
|---|---:|
| 生アクセスログ | 180日 |
| 相互RSS配分履歴 | 180日 |
| 日別集計・ランキング履歴 | 3年 |
| 通常RSS記事 | 3日 |
| 日次重複判定用ハッシュ | 3日 |
| 過去記事台帳 | 管理者が削除するまで |

保存期間は管理画面から変更できます。

## サイト削除

サイト削除は非表示処理ではありません。「いいえ／はい、削除します」の確認後、サイトと関連データを完全削除します。エクスポートは自動実行されず、削除後は復元できません。

計測だけ止めたい場合は、サイト編集の「計測有効」を外してください。停止では過去データを削除しません。

## 相互RSS配分

対象サイトが直近24時間に受け取った有効アクセス全体を100%として、送信元サイトごとの割合を配分します。

計算順序：

1. 除外サイトを除く
2. 特別サイトは固定の特別配分ポイントを使う
3. 弱小サイト救済対象へ最低ポイントを保証する
4. 優遇サイトへ倍率（初期150%）を掛ける
5. 全体を100%へ正規化する

配分履歴は管理画面とDBに残ります。

## RSS画像

使用する画像はRSSに含まれる次の情報だけです。

- `media:thumbnail`
- `media:content`
- 画像形式の`enclosure`
- RSS本文内の`img`

リンク先ページのOGP画像は取得しません。RSSに画像がない記事は、画像必須の表示場所と過去記事RSSから除外されます。

## セキュリティ

- PDOプリペアドステートメント
- CSRFトークン
- パスワードハッシュ
- セッションID再生成と安全なCookie属性
- ログイン試行制限
- サイトID・サイトキー・登録ドメイン照合
- cron秘密キーと同時実行ロック
- HTML/CSSテンプレートの危険要素除去
- 相互リンク依頼の署名付きフォームトークン、使い回し防止、ハニーポット、計算認証、送信回数制限
- メールヘッダー改行除去
- RSSのSSRF、内部IP、危険なXML、過大レスポンス、過剰リダイレクト対策
- 管理・確認・APIページの`noindex`
- `config`、`src`、`storage`へのWebアクセス拒否
- IPアドレスの代わりにHMACハッシュを保存

Nginxでは、`config/`、`src/`、`storage/`へのアクセス拒否をサーバー設定へ追加してください。

## 動作確認

サーバー上で全PHPファイルの構文を確認できます。

```bash
find . -name '*.php' -print0 | xargs -0 -n1 php -l
php tests/run.php
```

その後、インストール、サイト登録、タグ計測、cron、各表示パーツ、相互リンク依頼、年次エクスポートを順に確認してください。
