# 阿修羅（Asyura）

PHP製のサーバー設置型・複数サイト対応アクセス解析ツールです。アクセス解析、逆アクセスランキング、相互リンク、相互RSS、過去記事再配信、お知らせ、一般お問い合わせ、相互リンク依頼を1つの管理画面で扱えます。

## 主な機能

- サイト単位の非同期JavaScript計測タグ
- PV、セッション、日次UU、内部・外部・表示パーツクリック、流入チャネル、ページ別、端末・ブラウザ・OS解析
- 実滞在時間、スクロール深度、直帰率、エンゲージメント率、URL到達コンバージョン
- 7日・30日・90日の期間切替、日別グラフ、色分けした集計表
- イベントIDによる二重計測防止、Beacon失敗時のFetch送信、タグの二重初期化防止
- 許可外Origin、無効なサイトキー、異常頻度、Bot・自動操作の検知記録
- Googleアカウントを全体で1回接続し、サイト別にSearch Consoleプロパティを割り当て
- http/https、www、末尾スラッシュ、計測パラメーターのURL正規化
- 旧URL、別ドメイン、iframe・外部ツール経由URLの手動統一
- 検索エンジン・不要流入元の除外
- 3日集計を初期値とした逆アクセスランキング
- A〜Jの相互リンク表示場所（最大10か所・各場所は設定済みリンクを全件表示）
- A〜Jの相互RSS表示場所
- HTML/CSSとショートコードによる表示デザイン
- 1サイトへの複数RSS登録
- RSS内の画像だけを利用する画像RSS（OGP補完・No Image補完なし）
- 24時間の受け取りアクセス割合による相互RSS配分
- 優遇、特別、弱小サイト救済、除外の組み合わせ
- 過去記事台帳とランダム再配信RSS
- 相互リンク依頼フォーム、受付番号、申請状況確認、登録・解除通知
- サイト別の一般お問い合わせフォーム、受信一覧、未読・確認中・対応済み管理
- 署名付きトークン、使い回し防止、ハニーポット、計算確認、二段階回数制限
- 相互リンク申請フォーム上部の定型文2種類と自由入力文
- サイト別・全体のお知らせ
- 年次CSV/ZIPエクスポート、アーカイブ閲覧、エクスポート後のDB削除
- WordPress風の管理画面

## 動作環境

- PHP 8.1以上
- MySQL 8.0以上、またはMariaDB 10.5以上
- Apache 2.4以上（Nginxでも利用可能）
- PHP拡張：PDO MySQL、mbstring、cURL、SimpleXML、ZipArchive
- HTTPS推奨

## インストール

1. リポジトリ一式をサーバーへ配置します。
2. ブラウザで `https://設置URL/install.php` を開きます。
3. DB名、DBユーザー、DBパスワードを入力します。
4. インストーラーが設置URLを自動判定し、DB・テーブル・`config/config.php`を自動作成します（DBホストは`127.0.0.1`、ポートは`3306`です）。
5. `login.php`からログインします。

`config/config.php` はサーバー固有のファイルで、更新時に上書き・削除しないでください。特に `app_key` を変更すると、保存済みのGoogle OAuth認証情報を復号できなくなり、アクセス解析の訪問者・セッション識別も切り替わります。更新前に必ずバックアップし、同じ値を継続して使用してください。このファイルはGitの管理対象外です。

初期ログイン情報：

```text
ユーザー名：admin
パスワード：password
```

強制変更はしません。公開サーバーでは、ログイン後に「設定」から変更することを推奨します。

DBユーザーにデータベース作成権限がない場合は、空のDBを先に作成し、そのDB名をインストーラーへ入力してください。テーブルは自動作成されます。

### XAMPP

`htdocs/Asyura`へ配置した場合：

```text
インストール：http://localhost/Asyura/install.php
ログイン：http://localhost/Asyura/login.php
```

Apacheの`mod_rewrite`と`.htaccess`を有効にしてください。

## cron

30分ごとに実行します。管理画面の「設定」に専用URLが表示されます。

URL方式：

```text
https://設置URL/cron/run.php?key=自動生成キー
```

CLI方式：

```bash
php /サーバー上のパス/Asyura/cron/run.php
```

cronはRSS取得、相互RSS配分計算、保存期限を過ぎたデータの整理を行います。同時実行はDBロックで防止します。

## 計測タグ

「サイト登録」でサイトを登録すると専用タグが発行されます。登録サイトの全ページへ同じタグを設置します。

```html
<script src="https://設置URL/assets/tracker.js"
        data-site-id="サイト専用ID"
        data-site-key="サイト専用キー"
        async></script>
```

タグは非同期で動作します。阿修羅への通信失敗が設置サイトの表示を止めることはありません。

## 保存期間の初期値

| データ | 保存期間 |
|---|---:|
| 生アクセスログ・セッション・不正アクセス検知 | 180日 |
| 相互RSS配分履歴 | 180日 |
| 日別集計・ランキング履歴 | 3年 |
| 通常RSS記事 | 3日 |
| 日次重複判定用ハッシュ | 3日 |
| 過去記事台帳 | 管理者が削除するまで |

保存期間は管理画面から変更できます。

## サイト削除

サイト削除は非表示処理ではありません。「いいえ／はい、削除します」の確認後、サイトと関連データを完全削除します。エクスポートは自動実行されず、削除後は復元できません。

計測だけ止めたい場合は、対象サイトから計測タグを外してください。過去データは削除されません。

## 相互RSS配分

対象サイトが直近24時間に受け取った有効アクセス全体を100%として、送信元サイトごとの割合を配分します。

計算順序：

1. 除外サイトを除く
2. 特別サイトは固定の特別配分ポイントを使う
3. 弱小サイト救済対象へ最低ポイントを保証する
4. 優遇サイトへ倍率（初期150%）を掛ける
5. 全体を100%へ正規化する

配分履歴は管理画面とDBに残ります。

## RSS画像

使用する画像はRSSに含まれる次の情報だけです。

- `media:thumbnail`
- `media:content`
- 画像形式の`enclosure`
- RSS本文内の`img`

リンク先ページのOGP画像は取得しません。RSSに画像がない記事は、画像必須の表示場所と過去記事RSSから除外されます。

### RSS・ランキングのデザイン編集

- 相互リンクで登録完了したサイトと、相互RSSのみを利用するサイトの有効なRSSをすべて配分対象にします。表示場所ごとのRSS選択は廃止し、以前の選択設定も配信対象を制限しません。
- RSSは変換率から求めた返還残数に応じて配分します。通常設定で逆アクセスが0、返還目標に到達済み、RSS配分除外、停止・未承認のサイトは配分しません。RSS未登録・有効な記事がない場合も表示されません。画像RSSは使用可能な画像がある記事に限ります。
- 相互リンクサイト登録の「除外サイト」は、対象サイトの相互リンク・RSS・公開ランキングを非表示にします。「RSS配分から除外」はRSSだけを停止する設定です。
- 画像RSSは4列（スマートフォンでは2列）の画像カード、ランキングは順位・サイト名・IN数の初期デザインを用意しています。以前の初期HTML・CSSをそのまま使っている枠にも適用し、編集済みの組み合わせは保持します。
- HTML・CSS編集画面でサンプル／実際の配信候補、パソコン／スマートフォン幅を切り替えてプレビューできます。サンプルは公開配信やアクセス計測に使いません。
- 横幅・高さの入力欄はありません。`.asyura-rss` / `.asyura-ranking` / `.asyura-links` のCSSで指定してください。内容に合わせた高さの自動調整を利用するには、編集画面の新しい設置タグ（iframe＋スクリプト）へ貼り替えてください。以前のiframeタグも引き続き表示できます。

既存の計測タグ（`assets/tracker.js`）が設置されているサイトでは、古いiframeだけのタグも高さ自動調整の対象になります。阿修羅の本番ファイルを更新し、計測スクリプトのキャッシュを更新してください。計測タグがないサイトでは、編集画面の新しい設置タグを使ってください。自動調整は同じ阿修羅設置先の表示パーツに限定し、他サービスのiframeには適用しません。

### 表示パーツのリンク先とクリック計測

相互リンク・画像RSS・テキストRSS・逆アクセスランキングのリンク先は、相手サイトや記事の直接URLです。クリック時は画面遷移とは別に署名付きPOSTで計測し、返還アクセスの集計に反映します。JavaScript無効・通信遮断などで計測できなくてもリンクは利用できます（そのクリックは返還数に反映できない場合があります）。保存済みのHTMLで `{url}` を使っていれば、本番ファイル更新で直接URLへ切り替わります。以前にコピーされた計測URLのGETアクセスは互換性のため引き続きリダイレクトします。
